# Quickstart

## Prerequisites
- Python 3.x installed and available in PATH
- Node.js installed (for running the JavaScript script)

## Run the Python script
From the repository root:
- Navigate to content/project/unit12
- Run: `python clean_names.py`

## Run the JavaScript script
From the repository root:
- Navigate to content/project/unit12
- Run: `node cleanNames.js`

## Record outputs
- Capture the printed output from both scripts in your Part A1 notes.
- Document any differences in ordering, casing, or error behavior.
