# eportfolio Constitution

## Core Principles

### I. Spec-Plan-Tasks Alignment (MUST)
All features MUST have a spec, plan, and tasks set that agree on scope, structure, and deliverables. If any artifact changes, the others must be updated to remain consistent.

### II. Minimal, Safe Script Changes (MUST)
Educational scripts MUST receive at most one light modification each, preserving the original task behavior. Changes MUST be documented inline in the script.

### III. Evidence-Backed Writing (MUST)
Written deliverables MUST reference observed outputs, modifications, and credible sources where required.

## Additional Constraints

- Planning artifacts MUST live under specs/ and MUST NOT be moved into content/.
- Publishable content remains under content/ and assets/.

## Development Workflow & Quality Gates

- Before implementation, run speckit analyze and resolve CRITICAL issues.
- Word-count targets must be checked within ±10% for each part.

## Governance

This constitution supersedes all other practices. Amendments require documentation of the change, its rationale, and the date.
